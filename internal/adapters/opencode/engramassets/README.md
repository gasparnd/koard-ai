## Runtime prerequisites and effects

Use Engram 3.7.2 on the OpenCode server's PATH. Leave `ENGRAM_BIN` unset or set
it to exactly `engram` so the plugin and MCP resolve the same executable.
Both inherit the host environment. Do not configure them against different
stores/endpoints; this is not an isolated memory database. Setup does not inspect
or change stored memories, global configuration, or running services.

When OpenCode loads the plugin, Engram may start its local server, register root
sessions, capture prompts and import a project's `.engram/manifest.json`. These
are provider runtime effects, not installer actions. Read the provider protocol
before opening a project containing imported memories.

OpenCode 2.2.6 activates the first plugin with a given ID. A global `engram`
plugin can take precedence and report this copy as a duplicate. Installation
does not inspect every ambient plugin or certify activation. Do not remove
global configuration automatically. Check plugin/MCP status in the host before
relying on memory; configuration alone does not prove continuity.
