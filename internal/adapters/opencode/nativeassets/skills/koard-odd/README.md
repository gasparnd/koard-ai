Generated by Koard native setup, bundle v1.

This skill guides the Koard primary agent inside an ordinary OpenCode session.
It accepts the user's request and repository context; its output is proportional
implementation or explanation with observed verification limits.

Ask for a bounded feature normally. A request to explain a function must remain
read-only; an authorized bug fix should include a failing regression test and
observed checks. A missing product decision should cause one focused question.

Instructions influence agent behavior; they are not a sandbox. OpenCode owns
tool permissions. Existing Koard deterministic commands retain their own input
and consent checks, but do not govern arbitrary live edits. Engram requires a
working, separately configured host integration with authoritative attribution.
